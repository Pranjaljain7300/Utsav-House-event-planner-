# Utsav House Website

Responsive multi-page event planner website.

Pages:
- index.html — Home
- services.html — Services
- corporate-events.html — Corporate Events
- weddings.html — Wedding Planning
- catering.html — Catering Service
- gallery.html — Gallery
- blog.html — Blog
- contact.html — Contact

Assets:
- assets/style.css
- assets/script.js

Notes:
1. Replace placeholder phone/email/social links in the header/footer/contact page with official Utsav House details.
2. Gallery/hero images use Unsplash image URLs, so internet is required to load them.
3. The contact form is a front-end demo; connect it to your backend, Formspree, Netlify Forms, or an email/CRM service for live submissions.
4. Open index.html in a browser to view the site.
